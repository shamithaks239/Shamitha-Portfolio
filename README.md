# Shamitha-Portfolio
This code creates a simple portfolio website using HTML for structure and CSS for styling. 
The HTML part organizes the content into sections like header, navigation bar, about, skills , education and contact, while the CSS styles these sections with colors, padding , fonts, buttons, and margin to make the page look clean and organized. Internal CSS is used inside the style tag , which keeps everything in one file. The navigation links help users jump to different sections of the page, making the website easy to use and understand.
